## 📁 Структура
- **Магнитола** — материалы и прошивки для аудиосистем 
- **Программы** — набор программ для конфигураций и прошивок
	- **DashPlus** — программа для настройки и расширение функционала приборной панели
	- **ECUFlasher** — программа для прошивки блоков управления двигателем
	- **ELMConfig 2.19.0** — программа для настройки модулей через адаптер
- **Прочее** — электросхемы, предохранители и т.п
	- **image_dashplus** — изображения для приборной панели (работает только с DashPlus)
